Which protocol without a token is worth the most?

Every protocol below has no token yet. Each one is priced from the live market: a curve fitted on the 128 protocols whose token already trades, plus a shrunk category effect and three small, stated tilts. The board is sorted by that implied value, highest first. Two more fitted numbers sit beside it: token odds — how often protocols that look like this one already record a token — and expected value, the implied value times those odds. The biggest implied value is not always the best bet.

Token odds & expected value, fitted not guessed

The odds come from a logistic regression on all 758 protocols in the snapshot: does it record a token yet, given its TVL, its age and its category? A protocol's odds are the share of protocols that look like it and already record a token — a propensity, not a promise. Expected value is the implied value times those odds.
